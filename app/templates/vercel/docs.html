Arquitectura del Motor de Verificación

ValidatorHQ implementa una arquitectura desacoplada de alto rendimiento. Las peticiones entran a través de una API Gateway protegida con tokens de tenant, encolan trabajos en Redis Streams y son consumidas asíncronamente por trabajadores concurrentes.

Cliente HTTP (Multipart CSV) → Laravel Gateway → Redis Stream (job_dispatched) → FastAPI Workers → PostgreSQL 16

1. Subida y Validación de Lista CSV

POST /api/v1/jobs/upload

Sube un archivo delimitado por comas para iniciar la verificación automática.

curl -X POST https://validator.hq-mail.net/api/v1/jobs/upload \
  -H "Authorization: Bearer sec_tok_live_xxx" \
  -F "file=@leads.csv" \
  -F "chunk_size=250"

2. Endpoint Serverless Demo (/api/validate-demo)

POST /api/validate-demo

Ejecuta la deduplicación con SHA-256 (a coste cero), el análisis sintáctico y las validaciones perimetrales anti-SSRF.

3. Asistente RAG (/api/rag/ask)

POST /api/rag/ask

Consulta autónoma de la base de conocimiento para respuestas Zero-Touch.

curl -X POST https://validator.hq-mail.net/api/rag/ask \
  -H "Content-Type: application/json" \
  -d '{"question": "¿Me cobran los correos que dan error o Unknown?"}'
